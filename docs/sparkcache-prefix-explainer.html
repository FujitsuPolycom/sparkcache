06 Verified-or-recompute restore

Context is restored only after identity, quorum, compatibility, and chunk integrity checks pass.

Verified state or recomputation

A missing rank, malformed manifest, incompatible identity, or bad chunk hash becomes a miss. The request recomputes instead of consuming unverified KV state.

Identity stays topology-bound

Checkpoint digests, layout, TP/DCP, physical rank, chunk geometry, record schema, draft policy, and the prefix-key format remain part of the namespace.

Optional work cannot stall serving

An incomplete worker inventory or a full restore backlog makes the request compute normally. Unrelated inference does not wait for optional cache work.

08 Storage-mode boundaries

Implemented prefix reuse depends on payload semantics. Logical 256-token geometry alone does not make every stored object independently reusable.

Implemented Exact stored boundaries

Every supported storage mode may reuse an exact snapshot published for an earlier aligned request boundary when all ranks advertise it.

Implemented Sparse row-prefix aliases

A row source manifest produces bounded descriptor chains and selected earlier-prefix aliases. GPU-free regressions pass; live model-serving qualification remains absent.

Unsupported Opaque-page prefix aliases

An HMA snapshot cannot be shortened by truncating byte-partitioned chunk files. Page deltas support extensions from an exact base; they do not create arbitrary earlier-prefix aliases.
